# ПараПлан

Легковесный инструмент для удобного просмотра расписаний.

## Ключевые возможности

* 📅 **Расписание для студентов и преподавателей**: получение актуального расписания, оформленного согласно нуждам пользователя.
* ⚡ **Быстрый парсинг**: использование производительного бэкенда `calamine` для разбора Excel-файлов.
* 🔘 **Интерактивный UI**: удобный интерфейс на базе мессенджера Мах.
